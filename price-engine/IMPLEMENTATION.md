# پیاده‌سازی اتصال زنده

موتور اکنون آماده دریافت داده واقعی است، اما هر منبع باید Adapter/Client مخصوص خود را داشته باشد.

## قرارداد داده
هر Client باید برای هر نتیجه این اطلاعات را تولید کند:
- sourceId
- sourceName
- priceRial
- observedAtEpochMs
- matchScore
- sellerScore
- url
- partKey

## اولویت اتصال
1. API یا فید رسمی
2. صفحات عمومی محصول با اجازه دسترسی
3. داده تأمین‌کننده‌های خود فروشگاه
4. منابع عمومی پیام‌رسان در صورت وجود API/دسترسی مجاز

## امنیت و پایداری
- کلید API داخل کد ذخیره نشود.
- Rate limit رعایت شود.
- CAPTCHA و احراز هویت دور زده نشود.
- برای هر منبع timeout، retry و cache در لایه شبکه اضافه شود.
- اگر منبع پاسخ نداد، سایر منابع همچنان اجرا شوند.

## رفتار در داده ناکافی
اگر confidence پایین باشد، اپ باید «قیمت قطعی نیست» نشان دهد و از ساختن عدد جلوگیری کند.
