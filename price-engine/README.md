# Spare Parts Price Engine MVP

این پوشه هسته مستقل موتور قیمت‌گذاری است و می‌تواند بعداً به اپ اندروید متصل شود.

## اصل مهم
هیچ قیمت ساختگی تولید نمی‌شود. اگر داده معتبر کافی نباشد، خروجی باید «اطمینان پایین / داده ناکافی» اعلام کند.

## ورودی
PartQuery / NormalizedPart + PriceObservation از Adapterهای منابع.

## خروجی
MarketSnapshot شامل:
- کمترین قیمت معتبر
- قیمت مرکزی بازار (weighted median)
- بیشترین قیمت معتبر
- قیمت پیشنهادی فروش بر اساس درصد سود
- تعداد منابع
- confidence
- زمان آخرین مشاهده

## مرحله بعد
پیاده‌سازی Adapterهای واقعی و مجاز برای منابع منتخب، سپس کش محلی، زمان‌بندی به‌روزرسانی و اتصال به UI اندروید.
