# Spare Parts Price Engine

هسته‌ی پروژه برای قیمت‌گذاری دقیق لوازم یدکی.

## جریان داده
ورودی نام/شماره فنی/عکس/PDF → نرمال‌سازی → تطبیق کاتالوگ → دریافت مشاهدات قیمت → حذف داده مشکوک → محاسبه بازار → سیاست دقت.

## اصل ایمنی قیمت
بدون داده کافی، قیمت قطعی نمایش داده نمی‌شود.

## اتصال منابع
هر منبع با SourceConfig ثبت می‌شود. بنابراین ایساکو، سایت‌ها، کانال‌ها و تأمین‌کننده‌ها بعداً می‌توانند Adapter مستقل داشته باشند و تغییر یک منبع، موتور اصلی را خراب نکند.

## نکته
قیمت‌ها باید همراه زمان مشاهده و منبع ذخیره شوند. تبدیل تومان/ریال باید در مرز ورودی انجام شود؛ هسته با ریال کار می‌کند.
