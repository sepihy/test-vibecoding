# برنامه اساتید — MVP

اسکلت قابل‌اجرای MVP برای نمایش برنامه هفتگی اساتید، با رابط فارسی و راست‌به‌چپ.

## امکانات MVP

- نمایش ۷ روز هفته
- جست‌وجوی فوری استاد بر اساس نام یا دانشکده
- مشاهده برنامه هفتگی هر استاد
- نمایش زمان آخرین دریافت برنامه برای هر استاد
- نمایش برنامه‌های ثبت‌شده برای هر روز

> عمداً قابلیت «کلاس بعدی امروز» در این MVP وجود ندارد.

## ساختار

```text
app/
  days/[day]/page.tsx
  schedule/[teacherId]/page.tsx
  teachers/[teacherId]/page.tsx
  teachers/page.tsx
  globals.css
  layout.tsx
  page.tsx
components/
  DaysGrid.tsx
  TeacherSearch.tsx
lib/
  data.ts
```

## مدل داده حداقلی

- `Teacher`: شناسه، نام، دانشکده، آخرین زمان دریافت برنامه
- `ScheduleEntry`: استاد، روز، درس، گروه، ساعت شروع/پایان و مکان
- `Day`: کلید و عنوان روز

داده اولیه فعلاً در `lib/data.ts` قرار دارد تا بعداً به API یا دیتابیس واقعی متصل شود.

## مسیرهای اصلی

| مسیر | کاربرد |
| --- | --- |
| `/` | روزهای هفته + جست‌وجوی فوری استاد |
| `/teachers` | فهرست اساتید |
| `/teachers/:teacherId` | برنامه هفتگی و زمان آخرین دریافت برنامه |
| `/schedule/:teacherId` | نمای کامل برنامه هفتگی استاد |
| `/days/:day` | برنامه ثبت‌شده یک روز |

## اجرا

نیازمند Node.js و npm:

```bash
npm install
npm run dev
```

سپس برنامه روی آدرس توسعه Next.js اجرا می‌شود.

برای build تولید:

```bash
npm run build
npm start
```
