# معمای روزانه فارسی
نسخه اولیه اندروید با Kotlin و Jetpack Compose، رابط فارسی، صفحه خانه، بازی چندگزینه‌ای، ۱۰۰ مرحله و صفحه پیشرفت.

## ساخت APK
با push به شاخه `maamay-roozaneh-apk`، گردش‌کار GitHub Actions فایل APK دیباگ را می‌سازد و به‌عنوان artifact ذخیره می‌کند.

## محدودیت‌های نسخه اولیه
این نمونه ۱۰ سؤال پایه را برای ۱۰۰ مرحله تکرار می‌کند. حساب آنلاین، همگام‌سازی ابری، تبلیغات جایزه‌دار، تست دستگاه و امضای انتشار هنوز تکمیل نشده‌اند. این APK برای آزمایش است، نه انتشار نهایی.
