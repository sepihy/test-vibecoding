# دستیار قیمت لوازم یدکی

MVP اندروید فارسی برای جستجوی هوشمند قیمت قطعات و مدیریت منابع.

## صفحات
- قیمت‌یابی: ورود نام قطعه، خودرو یا شماره فنی
- منابع: افزودن لینک سایت/کانال و تشخیص نوع لینک
- تاریخچه: آماده برای ذخیره سوابق

## نکته
رابط کاربری آماده اتصال به Price Engine است. تا زمانی که Reader/API مجاز برای یک منبع پیکربندی نشود، اپ قیمت ساختگی نمایش نمی‌دهد.
