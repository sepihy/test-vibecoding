# دانش‌نت Android APK

این اپ یک WebView سبک است و محتوای دانش‌نت را از https://daneshnet24.ir/ می‌گیرد.
بنابراین تغییر برنامه، اطلاعیه‌ها، ظاهر و سایر محتوای سمت سرور بدون انتشار APK جدید به کاربران می‌رسد.

برای آمار نصب، اپ در اولین اجرا یک شناسه تصادفی ناشناس را فقط روی همان دستگاه نگه می‌دارد و
رویداد standalone_open را به API موجود دانش‌نت ارسال می‌کند؛ سرور آن را به‌صورت یکتا شمارش می‌کند.

نسخه 1.0.0 برای تست نصب تولید می‌شود. برای انتشار عمومی نهایی باید APK با کلید امضای خصوصی مالک پروژه امضا شود.
