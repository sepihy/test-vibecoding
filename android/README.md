# محاسبه‌گر اضافه‌کاری — Android MVP

نسخه اولیه اپ فارسی و راست‌به‌چپ برای محاسبه اضافه‌کاری و کسری کار با ورود شناور.

## قوانین
- شروع رسمی: ۰۷:۳۰
- شناوری: ۳۰ دقیقه تا ۰۸:۰۰
- موظفی: ۶ ساعت و ۳۰ دقیقه
- ورود قبل از ۰۷:۳۰: زمان زودتر اضافه‌کاری نیست.
- ورود بعد از ۰۸:۰۰: تأخیر نسبت به ۰۸:۰۰ کسری است.
- خروج بعد از پایان موظفی: از همان دقیقه اول اضافه‌کاری.
- استراحت/ناهار از کارکرد کم نمی‌شود.
- پنجشنبه: کل زمان حضور اضافه‌کاری.
- مرخصی کامل: صفر کسری و صفر اضافه‌کاری.

## UI
رابط کاربری فارسی، RTL، مینیمال و رسمی با ظاهر دانشگاهی، داشبورد امروز و نوار ناوبری پایین طراحی شده است.

## اجرا
پوشه `android/` را در Android Studio باز کنید و Gradle Sync و سپس Run را اجرا کنید.

این تغییرات روی شاخه `overtime-calculator-mvp` قرار گرفته و مستقیماً روی `main` اعمال نشده‌اند.
