# قیمت‌یار قطعات — Android MVP
ورودی: نام/شماره فنی، عکس/PDF و Excel/CSV.
Excel دارای تشخیص خودکار ستون‌های نام قطعه، شماره فنی، برند، خودرو، مدل، تیپ، قیمت، موجودی و تاریخ است.
اصل: قیمت قطعی فقط با تطبیق و کیفیت داده کافی نمایش داده می‌شود.
منابع هدف: WhatsApp، Rubika، Telegram/MellatSt، سایت‌ها و ایساکو؛ اتصال سرویس‌ها فقط از روش مجاز.
